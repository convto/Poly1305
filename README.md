## Poly1305

Poly1305 implementation for learning purposes. Do not use in production.

Implemented following [Daniel J. Bernstein , "The Poly1305-AES message-authentication code", 2005](https://cr.yp.to/mac/poly1305-20050329.pdf) and passed through the [RFC8439 Section 2.5.2](https://datatracker.ietf.org/doc/html/rfc8439#section-2.5.2) test suite.
